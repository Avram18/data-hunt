Briefing

Sie sind ein Agent in einer Daten-Jagd. Deine Mission: die Logs eines Gesprächs zwischen Xavier und Benjamin sicherstellen. Dazu verschaffen Sie sich Schritt für Schritt Zugriff auf Xaviers Rechner.

Was du dafür brauchst

Das Puzzle hat vier Schritte. Diese Erklärungen bereiten dich vor:

  • Verschlüsselte Nachricht knacken: eine Buchstabenverschiebung rückgängig machen (Caesar).
  • Session-Key berechnen: Diffie-Hellman mit g, p und den privaten Schlüsseln. Siehe Diffie-Hellman.
  • RSA-Sperre knacken: die Zahl n in ihre zwei Primzahlen zerlegen. Siehe RSA.
  • Passwort-Hash knacken: einen Hash-Wert nachrechnen und das Passwort finden. Siehe Hash.
Hinweis: Das Puzzle läuft komplett lokal in Git Bash. Es wird kein Server und keine Internetverbindung benötigt.
