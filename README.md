# Willkommen zum Data-Hunt Projekt
<h1>Worum geht es</h1>
<p>Im Prinzip geht es in diesem Projekt darum über den Datenschutz aufzuklären, allerdings wird das
mithilfe von Verfahren genauer behandelt.</p>
<p>Die Hauptverfahren die erläutert werden sind RSA, Diffie-Hellman und Hash.</p>
<h2>Terminal-Puzzle</h2>
<p>Nach den Erklärungen können die erläuterten Verfahren praktisch anhand eines Terminal Puzzles umgesetzt werden</p>
